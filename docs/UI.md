# UI specification

Version: 1.2  
Status: Approved

## Navigation

Jobs, Job detail, Packs, Applications, Tracker, Profile, Settings, Activity, Chat.

Removed from default nav: Ideas, Finance, Computer, generic Goals.

## Jobs

Cards: company, title, location, score, source, first seen. Click opens detail. Never auto-apply.

## Job detail

Required: official source URL, apply URL, requirements, rank reasons, optional company brief, actions (shortlist, generate pack, open official page in takeover, dismiss).

## Packs

Master vs candidate diff, evidence used, HR findings, approve or reject artifacts, then pack-level approve.

## Applications

State badge, takeover, submit approve, receipt, last snapshot.

## Settings

Preferences, scan interval, sources, model providers. Connect ChatGPT, connect Grok, connect another provider, or save an API key. Telegram bind, Google connect, board-risk disclosure.

## Profile

Uploads for the master resume, certificates, transcripts, licenses, awards, portfolios, publications, recommendations, and prior statements. Draft facts, confirm/edit/forget, voice samples. Drafts must show which evidence item a credential came from.

## Empty state

Unattended scans are public ATS only. LinkedIn and Indeed require a hunt session.
